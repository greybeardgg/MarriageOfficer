# Brand design system (imported)

Source: Claude Design project "Ryan Hogarth Marriage Officers Design System"
(https://claude.ai/design/p/a9951694-1ea5-4348-a4b8-ef79dad3db0a), read 2026-09-11.

- `styles.css` + `tokens/` are verbatim copies of the project's token files.
- `assets/logo-white.svg` is the project's vector lockup with the embedded
  content-credentials metadata removed; `logo-charcoal.svg` (#57585B) and
  `logo-slate.svg` (#465B69) are colour substitutions of it.
- `components/*.jsx` are notes on the three primitives the quiz uses, not code.

Fonts are Google-Fonts substitutions (Montserrat, Nunito Sans); real font files
are still owed. No photography has been supplied.
